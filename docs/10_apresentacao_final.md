## 3. Roteiro de fala

### Abertura

Na abertura, o grupo apresenta o sistema desenvolvido e explica que a demonstração tem como objetivo mostrar o funcionamento da aplicação em sua versão final.

A solução desenvolvida foi uma aplicação web para controle de estoque, voltada para o gerenciamento de produtos, categorias e usuários. A aplicação apresenta uma tela inicial de acesso, dashboard com indicadores gerais e telas específicas para consulta, cadastro e gerenciamento das informações do sistema.

### Desenvolvimento

Durante a apresentação, o grupo deve mostrar como o sistema funciona a partir da navegação demonstrada no vídeo.

A demonstração começa na página inicial de acesso ao sistema. Após entrar na aplicação, o usuário é direcionado ao dashboard, que apresenta uma visão geral do sistema com informações sobre produtos, categorias e usuários cadastrados.

No dashboard, são exibidos indicadores gerais, como:

- quantidade de produtos cadastrados;
- quantidade de categorias cadastradas;
- quantidade de usuários registrados;
- visão geral do estado atual do sistema.

Em seguida, a apresentação mostra a tela de produtos. Nessa área, é possível visualizar os produtos cadastrados no estoque. A demonstração também mostra que o sistema permite realizar ações sobre os produtos, como excluir um produto cadastrado e atualizar a listagem.

Depois, a apresentação mostra a tela de categorias, onde são exibidas as categorias criadas no sistema. Durante o vídeo, é demonstrado o cadastro de uma nova categoria chamada “chinelo”. Após o cadastro, a nova categoria passa a aparecer na listagem e também influencia os dados exibidos no dashboard.

Na sequência, é apresentada a tela de usuários. Essa tela mostra os usuários registrados no sistema. Como o acesso demonstrado é de um usuário administrador, é possível visualizar os usuários cadastrados e suas permissões dentro do sistema.

A demonstração também apresenta o cadastro de um novo produto. Após criar a categoria “chinelo”, é cadastrado um produto chamado “havaianas”, associado à nova categoria. Depois do cadastro, o produto aparece na listagem de produtos, a categoria aparece na listagem de categorias e os indicadores do dashboard são atualizados.

Com isso, o vídeo demonstra os principais fluxos implementados no sistema:

- acesso ao sistema;
- visualização do dashboard;
- consulta de produtos;
- exclusão de produto;
- consulta de categorias;
- criação de categoria;
- consulta de usuários;
- cadastro de novo produto;
- atualização dos dados exibidos pela aplicação.
